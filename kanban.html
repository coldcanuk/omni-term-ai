BUG-02P0 bug

Jumpbox default mounts the wrong host

No-arg launch turns the jumpbox hostname into the sshfs target. The remote script is unquoted. A failed mount still continues.

Fix and check
  • Separate “run on the jumpbox” from @target.
  • Pass the target as one quoted argument. Abort if sshfs fails.
  • Check: no sshfs of the jumpbox’s own name.
BUG-03P0 bug

Empty secrets clobber real tokens

Unset keys are exported as empty GH_TOKEN and friends, which hides keyring auth.

Fix and check
  • Export and set-environment only when non-empty.
  • Otherwise unset. Do not plant empty tmux vars.
BUG-04P0 bug

Azure key never enters tmux

omni_apply_tmux_env stops at Gemini. Endpoint and deployment live only in bashrc, which desktop launch often skips.

Fix and check
  • Inject the Azure key with the other non-empty secrets.
  • Store endpoint and deployment in the config file.
BUG-05P0 bug

Scratchpad and panic hit the wrong server

run-shell calls tmux with no -L omni-term-ai. Prefix-Space and Prefix-E miss the workspace socket.

Fix and check
  • Use tmux command lists on the current server.
  • Check against a second, default tmux server.
BUG-06P0 bug

First-run wizard is not on PATH

omni-config is called before the launcher prepends its own directory. Desktop and source runs miss it.

Fix and check
  • Resolve bindir first. Invoke "$bindir/omni-config".
